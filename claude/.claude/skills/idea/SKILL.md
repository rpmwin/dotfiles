# Idea capture

- MUST write one file per idea, never append to a shared list.
  - Tied to the current repo: `docs/ideas/YYYY-MM-DD-<slug>.md`.
  - Not tied to a repo: `~/dev/notebook/ideas/YYYY-MM-DD-<slug>.md`.
- MUST fill only what the user said; put gaps under Open questions, never invent.
- MUST commit it alone: `docs(ideas): <slug>`. Mid-task: one line to the user, then continue the task.

```markdown
# <title>

Status: raw | exploring | planned | dropped
Date: YYYY-MM-DD

## Problem
## Context
## Rough options
## Open questions
## Links
```
