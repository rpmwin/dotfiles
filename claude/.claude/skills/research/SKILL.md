# Web Research

- MUST use library docs via context7 before web search for API/framework questions.
- MUST send all planned searches in one turn; use `standard` mode, `extended` only when standard results are thin or stale.
- MUST fetch a page only when search snippets do not answer; ask the fetcher for the answer, not the whole page.
- MUST prefer official docs over blogs; flag blog-only claims as unverified.
- MUST stop at enough evidence to decide — not exhaustive coverage.
